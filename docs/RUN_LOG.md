# 실행 로그 (텍스트)

README의 스크린샷과 **같은 실행의 터미널 출력 원문**입니다. 사용자 입력도 화면에 보이는 그대로 들어 있습니다.
이미지를 볼 수 없는 환경에서도 실제 동작을 확인할 수 있도록 텍스트로 남깁니다.

- 실행 환경: macOS 12.7.6, `python3 main.py`
- 실행 일시: 2026-11-22
- 실행 순서: ① 첫 실행(파일 없음) → ② 퀴즈 풀기 3문제(33점) → ③ 퀴즈 풀기 5문제(70점, 최고 점수 갱신) → ④ 다시 실행(데이터 복원, 잘못된 입력, 점수/목록/기록)
- ②번 실행은 기록을 쌓기 위한 준비 실행이라 생략했습니다.

| 확인 항목 | 로그 위치 |
|---|---|
| 메뉴 출력, 파일이 없을 때 기본 퀴즈로 시작 | [1. 첫 실행 + 퀴즈 추가](#1-첫-실행--퀴즈-추가) |
| 퀴즈 추가, 정답 번호 범위 밖(`0`) 처리 | [1. 첫 실행 + 퀴즈 추가](#1-첫-실행--퀴즈-추가) |
| 퀴즈 풀기: 정답/오답 안내, 힌트, 결과, 최고 점수 갱신 | [2. 퀴즈 풀기](#2-퀴즈-풀기-5문제) |
| 재실행 시 데이터 유지(퀴즈 13개, 최고점수 70점) | [3. 다시 실행](#3-다시-실행--잘못된-입력--점수--목록--기록) |
| 잘못된 입력(`abc`, `9`, 빈 입력), 앞뒤 공백(` 4 `) | [3. 다시 실행](#3-다시-실행--잘못된-입력--점수--목록--기록) |
| 점수 확인, 퀴즈 목록, 게임 기록 | [3. 다시 실행](#3-다시-실행--잘못된-입력--점수--목록--기록) |

## 1. 첫 실행 + 퀴즈 추가

```text

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 게임 기록
7. 종료
========================================
선택: 2

📌 새로운 퀴즈를 추가합니다.

문제를 입력하세요: '영크크'의 뜻으로 알맞은 것은?
선택지 1: 젊은 세대의 감성, 트렌디함
선택지 2: 영원히 크게 웃는 사람
선택지 3: 영상 크리에이터의 크루
선택지 4: 영어 단어를 크게 읽기
정답 번호 (1-4): 0
⚠️ 잘못된 입력입니다. 1-4 사이의 숫자를 입력하세요.
정답 번호 (1-4): 1
힌트 (없으면 Enter): '늙크크'의 반대말이에요.

✅ 퀴즈가 추가되었습니다! (총 13개)

========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 게임 기록
7. 종료
========================================
선택: 7

👋 게임을 종료합니다. 다음에 또 만나요!
```

## 2. 퀴즈 풀기 (5문제)

```text
========================================
         🎯 MZ 신조어 퀴즈 게임 🎯         
📂 저장된 데이터를 불러왔습니다. (퀴즈 13개, 최고점수 33점)
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 게임 기록
7. 종료
========================================
선택: 1

몇 문제를 풀까요? (1-13): 5

📝 퀴즈를 시작합니다! (총 5문제, 힌트는 'h' 입력)

[문제 1]
'감다뒤'의 뜻으로 알맞은 것은?
  1. 센스가 없다, 감이 떨어졌다
  2. 감기가 다 뒤늦게 왔다
  3. 감자를 다 뒤집어 놓았다
  4. 감정이 다 뒤죽박죽이다
정답 입력 (1-4, 힌트: h): 1
✅ 정답입니다!

[문제 2]
젊은 감성의 '영크크'와 반대로, 올드한 감성이나 '영포티' 감성을 뜻하는 말은?
  1. 올크크
  2. 꼰크크
  3. 늙크크
  4. 옛크크
정답 입력 (1-4, 힌트: h): h
💡 힌트: '영(Young)'의 반대를 순우리말로 바꿔 보세요. 이 게임이 피하고 싶은 그것! (맞히면 이 문제는 절반 점수)
정답 입력 (1-4, 힌트: h): 3
✅ 정답입니다! (힌트 사용으로 절반 점수)

[문제 3]
'가슴에 국밥 쏟음'은 어떤 상황에서 쓰는 말일까?
  1. 감동적인 장면에 마음이 따뜻해졌을 때
  2. 식사 중에 국물을 옷에 흘렸을 때
  3. 배가 너무 불러서 속이 답답할 때
  4. 화가 나서 가슴이 뜨거워졌을 때
정답 입력 (1-4, 힌트: h): 2
❌ 오답입니다. 정답은 1번 (감동적인 장면에 마음이 따뜻해졌을 때)입니다.

[문제 4]
'감다살'의 뜻으로 알맞은 것은?
  1. 감기가 다 나아서 살 것 같다
  2. 감 다 살아있네, 센스가 좋다
  3. 감자를 다 살 수 있다
  4. 감정이 다 살아나서 울컥한다
정답 입력 (1-4, 힌트: h): 2
✅ 정답입니다!

[문제 5]
"이 순간 '동결건조'하고 싶다"는 무슨 뜻일까?
  1. 너무 추워서 얼어붙을 것 같다
  2. 음식을 상하지 않게 오래 보관하고 싶다
  3. 아무것도 하지 않고 쉬고 싶다
  4. 영원히 간직하고 싶을 만큼 소중하다
정답 입력 (1-4, 힌트: h): 4
✅ 정답입니다!

========================================
🏁 퀴즈 결과
  맞힌 문제: 4 / 5
  힌트 사용: 1회 (힌트 후 정답 1개)
  점수: 70점
========================================
🎉 새로운 최고 점수입니다!

========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 게임 기록
7. 종료
========================================
선택: 7

👋 게임을 종료합니다. 다음에 또 만나요!
```
